# 01 — Requirements

Each requirement has a measurable acceptance criterion and traces to the milestone in [08](08_IMPLEMENTATION_PLAN.md) that implements it. Verification commands live in 08; test design in [09](09_TESTING_STRATEGY.md).

## Functional requirements

| ID | Requirement | Acceptance criterion | Milestone | Final status (M7) |
|---|---|---|---|---|
| FR-001 | Download the C-MAPSS archive reproducibly. | `python scripts/download_data.py` fetches the archive from the URL in [04](04_DATASET_SPECIFICATION.md) §1, verifies the SHA-256 of the archive and of the FD001 files, and extracts to `data/raw/CMAPSSData/`. A checksum mismatch exits non-zero with a clear message. Re-running when files are present and valid performs no download. | M1 | **Met** — `tests/test_download.py`; `RUN_NETWORK_TESTS=1 pytest -m network --no-cov`; M7 fresh-clone Option A container download |
| FR-002 | Load FD001 files with the documented schema. | Loader returns DataFrames with exactly 26 named columns for train/test (`unit`, `cycle`, `setting_1..3`, `s_1..s_21`) and a 1-column RUL frame; real-data test asserts shapes 20631×26, 13096×26, 100×1. | M1 | **Met** — `tests/test_load.py`, `tests/test_real_data.py` |
| FR-003 | Validate loaded data. | Validation fails (raises) on: wrong column count, any null, non-integer unit/cycle, cycles not starting at 1 or not strictly +1 per unit, RUL row count ≠ test unit count. Real FD001 passes. | M1 | **Met** — `tests/test_validate.py`; `python -m predmaint.data.validate` |
| FR-004 | Compute RUL training labels. | `RUL = max_cycle(unit) − cycle`, clipped at `rul_cap` (default 125, configurable). Unit tests: last cycle → 0; clip applied; unclipped when `rul_cap=None`. | M2 | **Met** — `tests/test_labels.py` |
| FR-005 | Engineer features causally. | Sensors selected by the rule in [05](05_ML_DESIGN.md) §4; for each kept sensor: raw value, trailing rolling mean and std over `window_size` (default 30) rows of the same unit; plus `cycle`. Unit test proves changing rows after cycle *t* does not change features at *t*. | M2 | **Met** — `tests/test_features.py` (causality, isolation, truncation invariance) |
| FR-006 | Train and cross-validate a baseline. | StandardScaler + Ridge evaluated with 5-fold GroupKFold by `unit`; per-fold and mean±std MAE/RMSE recorded in metadata. | M2 | **Met** — `tests/test_train.py`; `reports/metrics_baseline.json` |
| FR-007 | Train and cross-validate a primary model. | HistGradientBoostingRegressor chosen by one bounded search of ≤ 12 configurations scored by GroupKFold CV RMSE (ADR-026); same CV protocol and outputs as FR-006; grid and winner recorded in metadata. | M3 | **Met** (bounded search per ADR-026) — `tests/test_train.py`; `reports/metrics_primary.json` |
| FR-008 | Evaluate on the official test set. | For each of 100 test units, predict at the last observed cycle; report MAE, RMSE (primary) and NASA score (secondary) against `RUL_FD001.txt`. | M2, M3 | **Met** — `reports/metrics_*.json`; `tests/test_real_data.py` (served model RMSE recomputed) |
| FR-009 | Select and persist the model. | Selection per ADR-024 (CV RMSE, tie-break CV MAE; test/CV disagreement flagged); `models/model.joblib` + `models/model_metadata.json` written with all fields of [05](05_ML_DESIGN.md) §9. | M3 | **Met** (rule per ADR-024) — `tests/test_selection.py`; `models/model_metadata.json` `selected_by` |
| FR-010 | `GET /health`. | Always 200 (ADR-028): `model_loaded: true` + `model_version` when the artifact is loaded; `status: "degraded"`, `model_loaded: false`, `model_version: null` otherwise. | M4 | **Met** (ADR-028) — `tests/test_api.py`; M6 container curl |
| FR-011 | `POST /predict`. | Valid request ([06](06_API_SPECIFICATION.md)) returns 200 with `predicted_rul`, `health_status`, `model_version`; value equals offline inference on the same input (contract test). | M4 | **Met** — `tests/test_api.py::test_predict_matches_predict_rul`; examples == sidecar (M6 containers, M7 fresh clone) |
| FR-012 | `GET /model/info`. | Returns metadata fields listed in 06 §4.3, read from `model_metadata.json`. | M4 | **Met** — `tests/test_api.py::test_model_info_fields_and_types` |
| FR-013 | Structured errors. | Every 4xx/5xx response uses the envelope `{"error": {"code", "message", "details"}}`; each error code in 06 §6 has a test. | M4 | **Met** — `tests/test_api.py` (every code in 06 §6) |
| FR-014 | Dashboard shows model information. | Dashboard renders model version, type, and test metrics fetched from `GET /model/info`. | M5 | **Met** — `tests/test_dashboard_app.py`; M5 live session |
| FR-015 | Dashboard requests and displays predictions. | User selects an FD001 test unit (from `DATA_DIR`) or uploads a file in the raw FD format; dashboard sends the history to `POST /predict` and shows predicted RUL, health band, and sensor trend charts. No prediction is computed or stored in the dashboard. | M5 | **Met as amended** (CR-005: upload takes a docs/06 JSON body, not a raw FD text file) — `tests/test_dashboard_app.py`, `tests/test_dashboard_helpers.py`; M5 live session |
| FR-016 | Dashboard handles API failure. | With the API stopped, the dashboard shows an error message naming `API_BASE_URL` and does not crash; API 4xx error messages are shown verbatim. | M5 | **Met** — `tests/test_dashboard_app.py::test_app_survives_api_down` |
| FR-017 | Containerised deployment. | `docker compose up --build` starts `api` (port 8000) and `dashboard` (port 8501); `api` healthcheck reports healthy only when `model_loaded` is true (ADR-028); the dashboard waits for a healthy `api`; `scripts/smoke_test.sh` passes locally (arm64) and in the CI `docker` job (amd64). | M6 | **Met** — `bash scripts/smoke_test.sh` (arm64 local; amd64 CI run 42509206610); M7 fresh-clone Option A |

| FR-018 | Prediction interval (M8, CR-008, ADR-034). | `POST /predict` returns `rul_lower ≤ predicted_rul ≤ rul_upper`, both in [0, 125], with `interval_level` 0.8, when the interval artifact matches the served model, and nulls otherwise (point prediction byte-identical). `/health.intervals_loaded` and `/model/info.intervals` reflect the state. Empirical coverage of the nominal 80 % interval and mean width are measured on out-of-fold CV and the official test set (overall and per true-RUL bucket, unclipped and clipped truth) and recorded in metadata, `reports/metrics_intervals.json` and 16. No target coverage is promised. | M8 | **Met** — `tests/test_intervals.py`, `tests/test_api.py` (with/absent/mismatch), `tests/test_real_data.py` (committed artifact reproduces test coverage); smoke test asserts `lower ≤ point ≤ upper`; measured coverage in 16 §9 |

| FR-019 | Minimal anomaly detection (M9, CR-010, ADR-035). | `POST /anomaly` (same request schema and validation as `/predict`) returns `anomaly_score`, `normalized_score`, `threshold`, `is_anomalous`, `model_version` and, with `include_series=true`, one entry per full-window cycle; 503 `ANOMALY_UNAVAILABLE` without a matching artifact. Measured and recorded in `reports/metrics_anomaly.json` and 16, on train OOF and test engines: (1) per-engine Spearman(score, cycle), **acceptance: median > 0.7 on train OOF**; (2) false-alarm rate on healthy rows; (3) detection timing (fraction of life, RUL at detection, never-flagged fraction); (4) test engines flagged at last cycle by true-RUL bucket; (5) Spearman with the RUL prediction. | M9 | **Implemented; acceptance target NOT met** — median train-OOF Spearman 0.680 (IQR 0.506–0.818) ≤ 0.7; reported, not tuned (16 §10). Endpoint, artifact, dashboard and evaluation verified: `tests/test_anomaly.py`, `tests/test_api.py`, `tests/test_real_data.py`, smoke test |
| FR-020 | Calibrated 80 % interval (M10, CR-011, ADR-037). | **Pre-registered (written before any calibration number was computed):** empirical coverage of the conformally calibrated 80 % interval on the **evaluation half** of the training engines (random engine split, seed 42; Q computed on the other half from out-of-fold predictions) is within **80 % ± 3 points** (0.77 ≤ coverage ≤ 0.83) against the **capped** target. Test-set coverage is reported but is not the criterion. Point model, quantile models and their artifacts byte-identical. A miss is reported as not met, not tuned. | M10 | **Met (narrowly)** — evaluation-half coverage **0.777** (0.7768; band 0.77–0.83) with Q_eval = 1.320 from 50 calibration engines; before calibration 0.734. Shipped Q_final = 1.742; test coverage 0.850 (capped) / 0.750 (unclipped), reported only. Artifacts byte-identical (SHA-256). `tests/test_intervals.py`, `tests/test_api.py`, `tests/test_real_data.py`; 16 §9d |
